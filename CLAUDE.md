# first-site

**Goal:** test the full flow: edit on Mac → push to GitHub → Vercel deploys it.
**Stack:** one plain `index.html`, no build step.
**Run locally:** open `index.html` in VS Code, right-click → "Open with Live Server".
**Repo:** github.com/wcpuu/first-site (public).
**Deploy:** Vercel, auto-deploys on every push to `main`.
